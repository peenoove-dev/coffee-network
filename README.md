# ออกแบบแผนผังเครือข่ายร้านกาแฟ

เว็บ static ไฟล์เดียว (index.html) ไม่ต้องติดตั้งอะไร

## ขึ้น GitHub
git init && git add . && git commit -m "coffee network designer"
git branch -M main
git remote add origin https://github.com/<ชื่อคุณ>/coffee-network.git
git push -u origin main

## ขึ้น Render
1. New + > Static Site > เลือก repo นี้
2. Build Command: เว้นว่าง
3. Publish Directory: .
4. กด Create Static Site
(หรือใช้ render.yaml ผ่าน Blueprint)
